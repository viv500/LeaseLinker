# LeaseLinker

**Built at NSBEHacks 2024.** LeaseLinker matches people in different cities who want to swap homes temporarily, starting with university students moving for co-op terms.

## Why we built it

Canada's housing crisis hits students hard, especially those who move every few months for work. Pairing people who are moving in opposite directions frees up homes without building anything new.

## Run it locally

```bash
npm install
npm run dev
```

## Tech stack

React, TypeScript, Vite and Tailwind CSS.
